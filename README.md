<h1>📚 Resource Sharing Platform</h1>

<p>
A <strong>web application</strong> built to facilitate seamless <strong>resource sharing between students and teachers</strong>.  
This platform enables users to upload, access, and collaborate on educational materials with ease, fostering a more connected learning environment.
</p>

<p>
This project was developed during a <strong>3-hour hackathon</strong> — <em>"Promptology"</em> — where participants were challenged to design and prototype a functional web application from scratch, our project <strong>secured 1st place 🏆</strong> in the competition!
</p>
